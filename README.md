# Eunich John Sese — Software Engineer Portfolio

A professional, high-craft portfolio built with **Next.js 15**, **GSAP**, and **Framer Motion**. Designed to showcase a student-focused persona with a focus on impact, technical proficiency, and high-quality digital experiences.

![Portfolio Preview](public/og-image.png)

## 🚀 Features

- **Interactive Scrollytelling**: Immersive scroll-based animations using GSAP ScrollTrigger.
- **Cinematic Entrance**: Custom loading sequence with an animated monogram drawing for high-impact branding.
- **Custom Magnetic Cursor**: A fluid, high-performance custom cursor with contextual interactions.
- **Responsive Design**: Fully optimized for all screen sizes, from mobile to ultra-wide displays.
- **Modern Tech Stack**: Leverages the latest features of Next.js 15 and Tailwind CSS.
- **Direct Communication**: Integrated Gmail compose links for streamlined recruitment outreach.
- **Dynamic Skill Showcase**: Real-time animated skill progress bars highlighting core technical tools.

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [GSAP](https://greensock.com/gsap/) + [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Brand SVGs
- **Deployment**: [Vercel](https://vercel.com/)

## 📂 Project Structure

- `src/components/sections`: Individual page sections (Hero, Work, About, Contact).
- `src/components/ui`: Reusable UI components (CustomCursor, SideElements, LogoIcon).
- `src/lib/constants.ts`: Centralized site metadata and content configuration.
- `src/app/globals.css`: Core design system and global styles.

## 🏁 Getting Started

### Prerequisites

- Node.js 18+ 
- npm / pnpm / yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gamothalaman090-jpg/Portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) to see the result.
